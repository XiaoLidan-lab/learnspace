# 学习任务界面更新

按已确认的交互稿，将任务操作分为三个层次：顶部任务切换与保存状态、可收起的当前行动卡、右侧「计划 / 成果 / 助手」面板。桌面面板与画布并排，窄屏使用覆盖面板；原有模块编辑和自由学习保留。

## 操作与保护

- 当前行动提供模块跳转、完成／撤销步骤、添加成果；没有成果时允许确认后继续，完成任务仍检查步骤与成果要求。
- 编辑计划使用独立草案，保存前不修改任务；取消丢弃草案。保存校验任务作用域、过期进度、模块有效性；已有成果或已完成的步骤不能直接删除。
- 成果按任务查看，显示内容类型、关联步骤和保存快照，可定位原内容。跨任务定位先确认切换，再恢复对应模块和笔记。
- 掌握度与行动进度分开展示，沿用现有证据判断和学习助手；完成任务前保留 AI 总结确认。
- 任务切换保留原有内容隔离。抽屉／当前行动卡的展开偏好仅保存在本机，不增加云端字段或数据库迁移。
