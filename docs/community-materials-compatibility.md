# 社区学习材料预设兼容修复

## 原因与行为

发布入口与 007 触发器只接受材料流向自定义 AI；当前学习材料选择支持普通问答、翻译、测验、导图等工具，前后端旧限制导致正常工作台无法发布。

- 结构仍经 `safeTemplate` / `templateSchema` 白名单导出，不携带私人文件 ID、笔记 ID、检索关键词、聊天记录或 AI 结果。
- V2 与 V1 都允许用户明确勾选的附带资料，沿用原有 `shared_materials`、上传与安装协议。未勾选的正文不上传。
- 安装时新建独立资源和笔记 ID，不携带原笔记来源引用。附带文件的整篇文档预设可直接绑定到安装副本。
- 指定笔记、临时选区、检索关键词和具体条目仍需用户重新选择；不能因附带某一篇笔记就猜测它是原作者选择的篇目。
- 同一来源模块中多个私人篇目/条目导出后合并为一个待选择预设，避免移除私人 ID 后产生重复边。

## 数据库更新

新文件：`server/migrations/011_community_learning_materials.sql`。

前置为已经应用的 004（共享资料）和 007（V2 模板）。无需为了本次修复重跑旧迁移。011 检查两个校验触发器存在且启用，然后仅替换配置校验函数；不修改已有模板记录、账号、RLS、ACL、Storage bucket 或策略。可重复执行。

更新后的输入输出类型校验与 `connectionGraph.ts` 保持一致：支持多来源，限制每工具最多 12 个来源、全模板最多 48 条连接，保留私人绑定剥离、凭证检查、非法端点/字段、重复连接、单输入重复与环检测。显式分享的资料继续由独立的 004 触发器校验文件归属、Storage 元数据、模块类型、正文白名单和大小。

上线顺序：审核并授权执行 011 → 验证触发器 → 更新 Preview 前端 → 由用户选择合成资料验收发布与安装。发布用户现有内容需单独确认，本轮没有上传或公开它们。

回退前应保留当前函数定义；旧 007 的校验会重新拒绝新类型模板，不能把它当成与新前端兼容的回退。已有数据未被本次迁移改写。
