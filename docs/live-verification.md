## 邮箱登录问题记录（之后已使用密码登录完成验证）

浏览器回调发现 `otp_expired`：链接无效或过期。之后用户截图显示 `email rate limit exceeded`：项目登录邮件发送已达到限额。这是实际登录失败，不能将 Auth 设置接口可访问说成已登录成功。

界面已补充中文错误、发送/限流后的 60 秒本地防重复点击、发信成功的持续提示及网络错误反馈。本地倒计时不代表项目每小时邮件配额一定会在 60 秒后恢复。

如果使用 Supabase 内置邮件服务，官方文档说明项目默认最多每小时 2 封，且收件人受项目团队范围限制。需要普通用户登录时，应配置自定义 SMTP 并检查 Authentication 的 Rate Limits；同时把 `http://127.0.0.1:5173/` 加入允许的登录回跳地址。未修改云端认证设置，也未发送额外登录邮件。

随后用户完成密码登录。登录后的实际验证结果见下方；另一用户安装尚未验证。
