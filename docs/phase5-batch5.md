# 第五阶段⑤及整体验收

## 本批实现

沿用首页“AI 智能搭建”、方案编辑器、模块库、WorkspaceBus、自定义模块和 V2 安装事务，没有新增独立搭建平台。

- 新建 AI 方案使用 V2，结合目标推荐标准模块和必要的自定义模块，并给每个实例提供用途。注册表及实际输出端口传给模型；重复职责通过生成约束减少，职责与 Prompt 完全相同的自定义模块会被拒绝。语义相似功能仍需用户在预览中判断。
- 自定义配置复用已有 Schema 和编辑组件：名称、职责、多个命名文本字段、受控 `{{field}}` Prompt、文本/Markdown。禁止未声明变量、代码占位符和私人运行内容。
- 推荐连接复用既有端点、字段、端口、唯一输入和无环校验；PDF、选区、笔记保留待绑定标记，不包含原文件/笔记 ID、检索词或输入。仅公开文本/输出端口的 `needsBinding:false` 可规范化为省略，私人来源的错误标记仍拒绝。
- 在现有预览中编辑目标/步骤/成果、模块组合/用途/布局、自定义配置和连接。移除模块同步移除其草案连接和职责；字段改名后，无效连接须手动修正。无效配置禁止应用。
- 草案编辑不写入工作台。确认后生成新实例、重映射连接和任务用途引用，使用原有原子安装事务保存；创建连接不调用 AI。生成可取消，关闭后迟到响应不会创建工作台。
- 模块分工保存到任务计划，可在任务面板查看；原有任务隔离、来源、运行历史、成果、手动搭建与 V1 模板保持兼容。

## 社区 V2 状态与限制

- **本地 V2 模板已完成并验收**：保存、导入导出、安装、端点映射、私人来源重新绑定、独立编辑。
- **社区 V2 尚未上线验收**：007 已检查并通过本地 PostgreSQL/PGlite 兼容、隐私与幂等测试，本轮未执行线上 SQL、未发布模板。线上启用需要用户按顺序应用既有依赖及 `007_combination_templates.sql`，再验收社区发布/安装。学习工作台云端快照沿用已执行的 005/006，不依赖 007。

- 已有自定义模块工作台的 AI 原地布局调整继续保留保护限制；可手动改布局，或从首页新建 AI 组合，不覆盖已有配置。V1 标准模块的原有 AI 布局调整保持可用。
- 不包含自动级联、分支/循环、后台任务、任意代码执行或新 Workflow 编辑器。未部署、未发布、未执行线上迁移。
