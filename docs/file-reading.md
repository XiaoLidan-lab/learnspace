# 文件阅读

模块库的「文件阅读」复用旧 `pdf` 类型，旧工作台、连接端点和模板不需要迁移。

## 使用

1. 添加「文件阅读」，点击「上传文件」。
2. 支持 `.pdf`、`.doc`、`.docx`、`.md`、`.markdown`、`.txt`。
3. PDF 使用原有分页阅读、全文搜索和选段功能。Word／文本以正文区段阅读，可搜索并跳转；Markdown 可以切换排版预览。
4. 选中文字，通过「发送到」或已保存连线手动获取，来源保留文件名、版本和定位。
5. 原文件与 Word 提取的正文保存在本机 IndexedDB。刷新后恢复，不需要再次解析 Word。

## 范围和限制

- PDF 最大 50 MB；Word 最大 3 MB；Markdown／TXT 最大 2 MB，正文最多 100 万字符。
- Markdown／TXT 为本地 UTF-8 读取，其他编码提示另存为 UTF-8。
- Word 的 DOC／DOCX 均在浏览器后台线程本地提取正文，无需登录，不上传文件、不调用 AI。旧的服务端解析接口和部署函数已移除。
- Word 解析超时 10 秒后终止后台线程；DOCX 展开体积不超过 20 MB、最多 1000 个条目，正文最多 100 万字符。超限或损坏文件明确报错，不回退上传服务器。
- Word 提取正文，不还原分页、图片和复杂排版。定位单位为“文本区段”，不是 Word 原始页码。扫描件无 OCR。
- 复用版本化全文索引，按相关性提供片段，不默认把全文发送给模型。
- 与现有云端机制一致，原文件不自动跨设备同步；另一设备仍需重新上传绑定。Word／文本暂不可作为社区模板附带资料发布，保存组合模板只保留配置。
- 无需额外后端函数或数据库迁移。未部署、未发布。离线读取指文件解析不依赖服务器；本应用尚未提供断网后首次启动的 PWA 缓存能力，需先加载页面及阅读器资源。

## 验证

合成 DOC（真实 OLE）与 DOCX、Markdown／TXT 解码和完整分段、损坏文件、离线客户端、无网络请求、大小限制、IndexedDB 恢复、检索、来源版本校验均有自动化覆盖。合成 Word 夹具位于 `tests/fixtures/file-reading/`。

真实合成 DOC／DOCX 还通过生产 Worker 产物验证：在没有预置 Buffer、process、Node API 的隔离 JavaScript 环境中解析，并禁止网络请求。构建后可运行 `node scripts/check-word-worker.mjs` 复验。Safari 界面操作未实测。
