# 第五阶段④：模块组合模板

## 已实现

- 复用工作台保存/导出、模板社区、预览安装和原有安装事务；新增“本地组合模板”，不创建另一套社区平台。
- 含自定义 AI 模块或连接的工作台保存为 V2。布局、分组、公开设置、自定义模块职责/命名字段/受控 Prompt/展示方式以及手动连接均保留。普通布局模板仍可使用 V1，V1 导入、安装和原有显式资料分享继续兼容。
- 保存前可修改标题和说明，查看完整配置；自定义 Prompt 默认展开，必须勾选隐私确认才能保存或导出。社区发布同样要求确认 Prompt。常见凭证特征会被客户端和 SQL 拒绝；自由文本是否含个人信息仍需用户检查。
- V2 严格字段白名单：不包含文件、正文、笔记、任务、运行历史、输入/结果快照、来源资源 ID 或用户身份。模块/连接/分组改为模板内局部标识。
- 安装时重新生成工作台、模块、分组和连接 ID，重映射端点并深复制配置。重复安装得到独立工作台，安装后的编辑不影响模板及其他安装。
- PDF、选区、指定笔记连接仅保留结构并标记 `needsBinding`；笔记 ID 和检索词移除。安装后在自定义模块“模块数据连接 → 重新绑定来源”选择当前任务的新笔记/检索条件，再手动获取、预览、确认。不会读取原工作台内容或自动调用 AI。
- 校验模块配置、占位符、端点、输出类型、重复输入、依赖环、布局和 100 KB 限制。无效模板先整体拒绝，安装持久化继续使用既有 IndexedDB 事务。

## 数据与 SQL

- 本地模板使用独立的 `learnspace-templates-v1` IndexedDB，避免升级已有工作台数据库而阻塞旧标签页；入口仍在现有模板社区。仅在当前浏览器保存，可 JSON 导出/导入。
- 安装后的配置/连接继续使用现有工作台本地保存及按需 Supabase 同步；模板本身不自动上传。原有任务输入与运行历史仍隔离保存。
- 已有社区数据库启用 V2 前执行 `server/migrations/007_combination_templates.sql`（依赖已有 002–004）；迁移仅更新版本检查和模板白名单触发器，不更新已有内容，不更改 RLS。脚本可重跑。新安装的 `server/supabase.sql` 已同步。
- 本轮没有执行线上迁移或发布社区模板；007 使用本地 PostgreSQL/PGlite 验证。线上社区 V2 写入需用户自行应用迁移后验收，旧 V1 不受影响。

## 范围边界

- 不包含第⑤批 AI 组合推荐、自动执行器或新社区平台。
- 私人资料绑定不跨模板传递，使用模板的人需提供自己的内容；PDF 无 OCR 等既有限制不变。
- 本地模板尚不跨设备同步；可导出 JSON，或在执行 007 后由用户主动分享社区。
