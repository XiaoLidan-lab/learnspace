# 第四阶段实现与验收

## 实现范围

- `src/pdfIndex.ts`：本地逐页全文索引、断点恢复、并发读者共享解析任务、单读者取消不影响其他读者、版本隔离、全文短语搜索和关键词分块排序。每次扫描最多加载 12 页缓存，每个检索片段上限 1200 字符、重叠 160 字符，最终最多选六段。
- 索引使用独立派生数据库 `learnspace-pdf-cache-v1`，避免升级用户资料库引起已有标签页阻塞。清理索引只删除派生文本，不删除原 PDF、任务或笔记。`storage.ts` 兼容已经存在的本地数据库版本，不执行降级或删除。
- `pdfDocument.ts` / `PdfReader.tsx`：统一 PDF.js 加载入口；浏览器支持时按范围取字节；页面文字逐页解析。支持解析进度、取消/继续、搜索无结果、页码跳转、扫描页和解析失败提示。原文件仍受既有 50 MB 限制。
- `taskResources.ts` / `TaskCoach.tsx` / `taskIntelligence.ts`：只检索当前任务绑定文件；相关段落优先进入上下文预算；保留资源名称、版本、页码和模块定位；无命中不以文档开头冒充相关依据。检索覆盖情况可展开查看，PDF 文本只在本机索引，选中片段发送现有模型服务。
- `cloudService.ts`：读取与保存整个请求（含网络前的令牌获取）有 20 秒超时，超时不宣称保存失败或成功，而是要求核对版本；调用方取消也可立即释放 UI 等待。CAS 冲突不自动重试覆盖。
- `useCloudSync.ts`：同步中发生编辑时继续排队，已同步状态只对应实际确认的快照；失败记录对应实际发送的版本，避免误阻止尚未发送的新内容。沿用现有 Supabase CAS/RLS，不新增远端迁移。
- `TaskPanel.tsx`：同一任务面板内提供助手/成果回顾快捷定位，收起后点击可展开；没有活动任务时优先回顾最近完成任务。
- `registry.tsx`、`ModuleBody.tsx`、`App.tsx`、`MaterialPicker.tsx`、`vite.config.ts`：模块、任务面板、云端面板、助手、Markdown 预览按需加载；显式分离 React、Supabase、校验和 Markdown 依赖。生产首页 JS 和静态依赖合计约 449 KB（gzip 132 KB），不包含后续 PDF/Markdown 动态块。PDF worker 仍约 1.38 MB，仅 PDF 使用时加载。

## 浏览器验收与限制

Safari 验收使用专用测试账号，仅新建“第四阶段验收”标记工作台；不修改已有用户工作台，不发布模板或部署。5177 为第一会话，5178 为独立 Origin 的本地存储，用于验证从真实 Supabase 恢复。

- 已确认：生产构建预览首页启动；本地旧工作台保留；新任务刷新恢复；24 页 PDF 阅读；全文搜索尾页命中；刷新保留全文索引和页码。
- 系统文件选择器的自动化无法提交所选 PDF，最终由用户手动上传合成文件，后续阅读和搜索由 Safari 自动化操作确认。
- AI 输出不符合结构时拒绝保存并保留问题输入。校验诊断只记录字段路径和错误代码，不记录资料、回答、密钥或登录凭据。

实际验收结果：

- 63 项自动化测试全部通过；TypeScript 和生产构建通过，`git diff --check` 无错误。
- Safari 使用现有模型配置，从 PDF 第 24 页回答 ZXQ-742 的环境与控制标记，并保存 `[E1] document.pdf · 第 24 页 · 原始资料`；点击可回跳。首次模型推荐理由超过原先 300 字符上限而被拒绝；将说明文本的有界上限调整为 1000 字符（不改变动作与来源约束）后验证成功，超限与未知字段仍有回归测试。
- 动态计划首次建议移除未完成步骤，与用户“保留”意图不符；预览明确显示移除项，放弃后原计划不变。随后以已有成果且已完成的步骤生成新建议，校验要求保留该步骤；确认前进度 1/1，确认后 1/2，原完成状态和成果保留，历史计划保存一次。模型的自然语言说明不能代替实际差异检查。
- 合成选择题提交 1/1，掌握度为“初步理解”，仍明确只代表这些题目。关联笔记和测验两项快照后完成两步任务，真实模型生成总结、薄弱点和复习建议，云端显示已同步。
- B 任务无 A 的 PDF 绑定、笔记、测验、成果和助手记录，掌握证据不足。
- 5178 起初为零工作台、无文件的独立存储；通过真实 Supabase 恢复新工作台（当时版本 11，2 项任务），恢复了助手记录、反馈、1 次确认的计划历史、两步完成状态、1/1 测验依据、2 项成果和学习总结。刷新后仍保留；仅在该测试工作台暂停 B 后同步成功。随后使用第一会话中的旧版本提交合成反馈，进行真实并发冲突/超时验收，最终显示“云端请求超时，保存结果尚未确认”，本地合成反馈在刷新后保留。该次真实 CAS 冲突未获得服务端明确响应，不能计为真实冲突验收通过；CAS 拒绝覆盖与错误提示由 PGlite/RLS 和客户端回归测试覆盖。
- 恢复会话中引用文字及文件/版本/页码仍保留；原文件不存在时，点击定位直接提示重新绑定，避免先重新打开已完成任务再发现文件缺失。
- 助手显示统一清理内部步骤标识和 `done` / `hasArtifacts` 等字段；保存的原始回答与证据不改写。

AI 仍可能补充资料不支持的解释（本次总结就曾推测虚构控制标记的机制），来源白名单和结构校验不能保证语义事实正确，需要核验；掌握度规则仍以明确测验证据为准。

扫描版 PDF 不做 OCR；无文字页会明确提示。检索为本地关键词匹配，不具备语义向量和跨语言召回能力。索引包含全文，但模型只收到与当前问题相关的受限片段，不能声称模型已通读全文。原始文件和派生索引不上传到任务快照，跨设备需要重新绑定原文件；已有引用文字快照可保留。浏览器是否按范围加载 Blob 字节取决于浏览器实现，逐页解析与有限批量缓存读取不依赖此优化。
