# 模块扩展交付与验收

## 统一模块架构

- `definitions.ts`：服务端和浏览器共用的纯数据注册定义，包含类型、名称、分类、默认尺寸和能力。
- `registry.tsx`：定义与图标/React 渲染组件绑定。新增模块必须同时注册类型、定义与组件；AI 提示从定义表生成，不维护另一份允许类型。
- `model.ts`：`Mod.layout`、`Mod.group`、`Mod.locked` 是结构；`Mod.data` 是各实例内容；`Mod.settings` 是白名单公开配置。原四种模块字段保留以兼容已有本地数据。
- `ModuleProps` 是统一运行接口；模块仅通过 `update` 更新自身，通过 `bus`、`send`、`jump` 与其他模块协作。
- `WorkspaceEditor` 统一处理布局与容器。所有实例使用稳定 React key。标签切换和专注只隐藏其他容器，不卸载它们。
- `layout.ts` 独立实现碰撞检查、空位查找、布局预设、分屏、堆叠、拆分及 AI 方案应用。撤销恢复结构时合并最新模块内容，不回滚正文、资料或计时。
- IndexedDB 继续使用 `learnspace-v1` 的现有三个 store，新字段是兼容扩展，**无需清空或升级本地资料**。视频单文件最大 200 MB，PDF/图片最大 50 MB，文字稿最大 1 MB。

## 跨模块通信

每个工作台拥有独立 `WorkspaceBus`，支持 `selection.changed`、`selection.cleared`、`content.insert`、`source.navigate` 和 `module.focus`。相同选区去重，同类事件的递归重入被阻止，切换工作台替换总线，离开编辑器清空临时选区。

共享选区保留文本、来源实例、资源 ID/名称/版本、页码、视频时间点、URL、文本范围及创建时间。PDF/文本/便签/视频文字稿/网页摘录使用同一快捷工具栏。手动发送不会广播到所有实例；多个目标会要求选择。笔记追加以引用形式插入正文并保留结构化来源。

翻译模块只有在用户开启「同步选区」时自动接收，且只有开启「自动翻译」才触发请求。问答接收上下文后**不自动发送问题**。摘要与卡片接收材料后点击生成。共享选区也可在接收模块中主动选择使用。来源回跳打开原始实例；PDF 校验文件版本并跳页；视频在支持时定位；网页/视频原实例消失时提供打开原站的降级。

`useAI` 使用请求序号、输入标识与 AbortController。输入/选区改变、发起新请求或模块卸载均使旧结果失效；旧译文不能覆盖新选段。AI 请求统一走登录验证、限流、超时与输出校验服务。

## AI 与分享

布局生成认识全部 16 类型、12 列网格、24 实例和标签分组。调整现有布局时服务端要求输出 `instanceId`，前端按 ID 保留内容，并对未知/重复 ID 拒绝应用。用户预览后确认，预览期间原布局变化时拒绝应用，应用后可撤销。

卡片、测验、导图使用各自 Zod 结构校验；导图防重复节点与父子循环，选择题答案必须属于选项。不提供模拟 AI 答案。

导出/分享只保留名称、介绍、类型、标题、布局、组、锁定状态与公开设置。资源 ID、URL、文本、PDF、聊天、笔记、字幕、任务、卡片、日程、图片、本地文件和计时状态均不默认分享。模板安装生成新的实例/分组 ID，不复制私人内容。社区使用登录后直接发布与公开/本人可读的 RLS 规则，已有数据库执行 003_direct_publication.sql。

社区发布可另外逐项选择学习资料与逐篇笔记。白名单资料存入独立 `shared_materials` 清单，不混入 `template_config`；聊天、笔记结构化来源、未选正文不分享。文件进入私有 Storage 桶，RLS 仅允许作者和公开模板的读者读取被引用的文件；未发布的上传不可匿名下载。安装后生成独立文件和笔记 ID，来源绑定清空，工作台/文件/笔记通过一个 IndexedDB 事务保存，失败全部回滚。

## 测试与限制

单元/集成测试涵盖注册分类、布局合法性、事件隔离/去重、堆叠拆分、撤销内容保留、AI 实例对应、模板隐私、平台地址与能力、AI 输出结构、过期响应、HTTP 身份/限流/失败及 IndexedDB 的 16 模块保存恢复。

HTTP 测试的身份与模型使用受控替身，测试真实 Express 路由；IndexedDB 测试使用 fake-indexeddb，测试实际存储代码。它们不等同于真实云端 AI 或 Supabase 联调。

YouTube 与 Bilibili 适配依据官方嵌入地址。当前环境尚未验证实际播放、地域限制、登录限制或禁用嵌入视频。网页跨域选区不能读取，无法可靠检测所有 iframe 拒绝加载情况，因此外部入口始终可用。不会获取或绕过受限字幕。

## 手动验收步骤

1. `npm run dev`，打开 http://127.0.0.1:5173，新建空白工作台。
2. 模块分类应为四类各四种；搜索并分别添加 16 种模块，再添加同类型实例。
3. 输入文本、笔记、任务、日程，创建卡片和导图。切换五种布局后内容应不变；刷新后重新打开应恢复。
4. 移动/缩放模块；尝试重叠应提示并取消。通过标题方向键可移动。锁定后移动、缩放、删除不可用。
5. 分屏选择目标与方向。堆叠两模块，切换标签，拆出标签。撤销/重做后布局恢复，最新正文保留。
6. 开始番茄钟，堆叠、改变布局、进入/退出专注，时间应继续。刷新后重新打开仍以原截止时间显示剩余时间。
7. PDF 上传测试文件，翻页/缩放/搜索，选段发送到翻译、问答、笔记、摘要和卡片。多目标时只发送到选定实例。笔记引用回跳应定位到页码。
8. 选择文本/文字稿/网页摘录，翻译启用同步后应接收；未启用自动翻译时不请求。快速变更选区应不显示旧结果覆盖。
9. 给视频模块输入 YouTube/Bilibili URL，检查平台标签和外部入口；上传本地视频。导入 `.txt/.srt/.vtt` 字幕并选择文字。平台限制时在原站打开。
10. 为网页模块输入不能嵌入的站点，应可切换外部模式并打开原站，不宣称读取跨域内容。
11. 在 `.env` 配置 Supabase 和服务端 AI key，登录后测试翻译、摘要、卡片、测验、导图生成；请求失败时原内容保留。
12. 自然语言生成视频学习布局、三栏调整和标签堆叠，检查预览后应用、正文保留和撤销；多人同类实例应按 ID 匹配。
13. 导出模板 JSON，检查没有私人内容；导入应预览并创建新工作台。发布后，另一账号安装应看不到发布者资料。
