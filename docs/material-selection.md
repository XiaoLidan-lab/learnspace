# 学习材料与内容快捷操作（2026-10-20）

工作台不再显示连接工具或连线编辑。已有连接记录仍兼容读取；用户无需配置端口或获取输入。

## 两种用法

1. **从内容出发**：文件中选择片段后点击翻译、提问、制作卡片、生成练习或生成导图。笔记中可打开“用这篇笔记…”菜单。没有相应工具时自动添加，只有一个时直接复用，多个时选择目标。翻译、卡片、练习、导图在明确点击快捷操作后执行一次；提问先带入材料，再由用户输入问题。刷新和任务切换不会自动重放快捷操作。
2. **从工具出发**：在问答、翻译、卡片、测验或导图上方点击“选择材料／查看与调整”，勾选当前工作台可用的文件、具体笔记、AI 回答、译文、导图、卡片、网页摘录、视频文字稿或图片说明。文件可选“选中内容／整篇文档”。点击“使用这些材料”只保存偏好，再点击工具的生成／提问按钮执行；取消不修改任何设置。

文件阅读提供“用这份文件…”菜单，可针对整篇提问、生成整篇导图、根据整篇出题、提炼知识卡片。导图默认全文，翻译默认选区。多来源仍经过类型、有效性、数量与循环引用校验。

## 编辑、来源和数据

- 可随时“使用编辑内容”，或切回“使用所选材料”。编辑材料文本时自动切到编辑内容模式，上游变化不覆盖用户的草稿。
- 确认材料不会运行 AI，也不会清空原来的结果。生成失败保留旧结果。
- 材料选择保存在每个任务的模块状态中；来源笔记按工作台、具体篇目和当前任务校验。
- 明确保存的文件选区保留快照，可在刷新后继续使用；文件版本变化、任务不匹配或原文件不可用时不会冒用旧片段。
- 结果继续保留当时的来源定位和材料快照。已有笔记、卡片、测验、任务与运行记录兼容。
- 组合模板保存材料预设；输出时移除私人文件和笔记绑定，安装时重映射实例并要求重新选择私人材料。未执行线上迁移。
- 标准工具的整篇材料支持长文档：针对性问答检索全文，概述和导图、卡片、测验分段提取后汇总，不再直接因正文超过 23000 字符失败。单次请求和材料快照仍有大小保护，详见 [长文档处理](long-document-processing.md)。视频使用已提供的文字稿，图片使用手工说明；不新增视频解析或 OCR。
