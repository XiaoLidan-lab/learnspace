# 模块数据流体验版

## 使用方式

1. 在工作台点击“连接工具”，切换到紧凑的模块关系图，正文暂时隐藏。小卡片展示工具名称、类型和输入输出；右侧是输出，左侧是输入，字段名称始终可见，选择来源后高亮兼容输入。工具固定按“内容来源 → 理解与整理 → 练习巩固”分栏排列，辅助工具不显示在关系图中。关系图可滚动查看，退出后恢复原学习布局和内容，不改变模块尺寸或任务数据。
2. 从输出拖至输入，或者依次点击两端，有效连接立即保存。不打开确认弹窗，不读取内容，不运行 AI。
3. 指定笔记、PDF 关键词、待办条目等在上方行内“来源设置”中选择。关键词离开输入框或按回车即保存，不需要再次确认。
4. 连接模式以模块和连线为主，不展示重复的连接列表或大块设置面板。选中连线后，仅显示“传递内容／打开来源／断开连接”等小操作；指定笔记等需要绑定时可点“选择来源”。传递后可立即撤销；继续编辑后的内容不会被撤销覆盖。学习模块正文不展示连接管理面板。
5. 点击连线可操作或断开关系。不可见的旧异常连接通过“检查不可用连接”逐条处理。删除连线不会删除已获取内容、旧结果、文件或笔记。

模块库分类与连接图统一：

- 内容来源：PDF、网页、视频、图片（分别传选区、摘录、文字稿及图片说明，不增加媒体识别能力）。
- 理解与整理：问答、翻译、总结、导图、笔记。
- 练习巩固：知识卡片、测验；测验结果仍可用于任务掌握度，无需连线。
- 辅助工具：待办、日历、番茄钟，不参与新建数据连接。

新建列表移除文本、便签和自定义 AI，AI 推荐目录也隐藏它们；已有实例、正文、历史连接、任务、模板仍可读取，不删除用户数据。旧高级连接按需展示原端点，以便查看和移除；不再允许从练习巩固成果或辅助工具新建输出连接。

以下为底层兼容能力，旧模板和运行数据继续使用，并非默认展示全部端口。

## 输入输出

- PDF：关系图默认只展示“选中的片段”输出，不再要求用户选择文件或关键词端口。已有检索或文件连接继续保留，并按需展示原端点以便管理。
- 网页：人工摘录、网址；接收安全 HTTP/HTTPS 网址。不读取跨域全文。
- 视频：已导入文字稿、视频引用；接收视频引用或追加文字稿。不自动转录。
- 图片：说明文字、图片引用；接收图片引用或说明。不自动 OCR。
- 文本、便签：正文、选区；多来源追加。
- 问答：最新回答；多来源参考资料独立保存，不覆盖用户问题，不自动提问。
- 翻译、总结：生成结果；多来源材料。获取翻译输入时关闭自动翻译与选区自动同步，不自动调用 AI。
- 导图：层级大纲；接收生成材料或导入已有大纲，重映射节点标识并校验层级环。
- 笔记：指定篇目；接收多来源内容，默认新建笔记；可在目标工具中明确选择已有篇目追加，绝不回退写入其他篇目。
- 卡片：整组或选定卡片；接收制卡材料或导入卡片，安装新条目标识。
- 待办：全部或选定事项；接收文本清单或事项，新增内容默认未完成。
- 测验：题目、已提交结果；接收出题材料。未提交不能输出结果，简答题不自动判分。
- 日历：全部或指定日程；接收日程或事项。事项需要先在行内设置日期和时间，校验后直接添加。
- 番茄钟：当前计时状态，不是历史专注记录；接收一项专注内容，不自动开始计时。待办有多项时先明确选择一项。
- 自定义 AI：保留命名字段单来源和历史运行，获取后直接填入字段，可撤销，运行仍需点击。

## 校验和兼容

同一输入能否多来源由端口声明决定；工作台最多48条连接，每个工具最多12个来源。拒绝不支持的端口、缺失实例、类型不匹配、自连接、重复连接、单来源输入重复占用及依赖环。

取数时再次校验任务、来源版本、连接配置和目标修改状态。任务切换或模块卸载会取消未完成取数；显式复用另一任务内容时保留快照并解除实时取用标记。重复追加同一版本到同一目标会被拦截。

连接和取用快照通过现有工作台存储持久化；兼容旧的自定义模块连接。模板保留配置和关系，去除正文、运行及取用快照，安装后重映射端点，私人来源重新绑定。

扩展连接支持本地模板保存、导出和安装，以及原有工作台云端负载格式；社区模板服务端007校验尚不支持扩展连接，因此客户端阻止这类发布并提示本地保存。没有执行线上迁移或部署。

## 验证边界

使用合成数据覆盖端口能力、类型、单/多输入、来源、笔记篇目与任务隔离、卡片/大纲导入、日程日期、测验结果、文件引用、云端序列化和模板隐私；执行 TypeScript、构建和全量回归。101项回归测试通过；真实AI使用两份合成资料（7与11个样本）正确回答18，并在内存完成AI回答到笔记的传递，来源三条、内容类型AI，未写入任何用户数据。

本轮未读取或操作真实用户记录，未做真实 Supabase 写入或跨设备实测。Safari 的真实拖线、触屏及视觉验收尚未完成，不能将静态渲染或单元测试视为浏览器验收。手册截图尚未更新。

## 连接内容范围

选中“文件阅读”的内容连线后，在上方紧凑操作栏选择“数据范围”：**选中内容 / 整篇文档**。范围按连接保存；新建文件阅读→AI 翻译连接默认选中内容，新建文件阅读→思维导图连接默认整篇文档。已有连接未设置范围时继续按选中内容处理，不自动改动旧数据。

范围改变本身不取数、不运行 AI、不覆盖现有材料或结果。点击“传递内容”按新范围获取材料，之后在目标工具执行翻译或生成导图；AI 问答在发送问题时获取。整篇模式复用本地逐页索引，并在正文中保留页码／文本区段标记；快照保留范围与版本。空选区不会退回全文，整篇不会退回文档开头。

当前整篇传递最多 23000 字符（含定位标记），自定义 AI 单字段仍为 8000 字符，多来源合计仍受现有上限限制。超限、存在无法提取正文的页或读取取消时明确失败，不截断、不覆盖原输入。整篇模式暂不提供超长文档分段 AI 汇总。文件仍需在本机可用，模板保留范围配置但不携带私人文件正文，安装后重新绑定文件。

本地社区模板 SQL 白名单同步支持范围字段，仅更新脚本与内存数据库测试，未执行任何线上迁移。范围与执行链路已在 Safari 使用隔离数据验证，具体覆盖见下方验收记录链接。

## 执行时取数（2026-10-19 修复）

翻译、卡片、测验、导图与旧总结模块现在与问答一样，可以在已有内容连线、但文本框为空时直接点击执行。执行时沿连线读取范围内材料，成功后保存输入快照和结果。已手动编辑的材料优先，不被上游覆盖；失败保留原内容。连接模式的“传递内容”仍用于提前查看材料、笔记追加和结构化内容导入，建线与选区变化不自动调用 AI。图片展示提供手工填写的图片说明，不自动识别图像；网页使用用户可访问和粘贴的摘录，视频使用已提供的文字稿。
