# 工作台 UI/UX 产品化重构

## 审查与优先级

基于当前组件、此前工作台截图及 Safari 实际页面审查，沿用现有浅色与蓝紫色体系，不重写 PDF、AI 或任务服务。

| 优先级 | 发现的问题 | 调整方式 |
| --- | --- | --- |
| P0 | 材料摘要、输入框和“使用编辑内容”混杂，容易误判实际出题内容 | 一个紧凑入口；已有材料与直接输入分开；在同一面板选择范围 |
| P0 | 快捷发送无法准确识别手动改过的输入 | 记录最近接收内容，真正修改过的草稿才确认覆盖；材料更换也有草稿保护 |
| P0 | 生成与答题混在同一界面 | 初始生成、答题、解析、重新出题分成状态，取消重新生成不动原题与记录 |
| P1 | 标题栏堆满编辑、复制、锁定等图标 | 专注常驻，其余收入带文字的更多菜单，支持键盘与焦点返回 |
| P1 | 问答上方材料管理区抢占对话空间，历史来源重复 | 材料入口靠近输入框；每条回答的来源单独折叠，始终引用当时来源 |
| P1 | 笔记正文被工具、来源及技术说明挤压 | 正文单独滚动；操作与来源渐进展开，引用去重；保留正文和保存语义 |
| P1 | 卡片仅有长列表，翻卡学习不突出 | 默认单卡复习、翻面与上一张/下一张；集合及编辑入口继续保留 |
| P2 | 窄模块换行、过小图标和多层边框 | 统一容器、字号和操作尺寸，容器查询适配窄模块；减少嵌套边框 |

## 实施分组与完成情况

1. **基础与材料**：统一标题栏、更多操作、材料摘要与范围面板；保留任务隔离、旧连接读取和多来源校验。材料选择取消不提交，缺少来源时仍有明确提示。
2. **翻译、问答、笔记**：原文与译文分区，宽模块并排；语言设置按需展开；译文复制/笔记/卡片仍可用。问答对话为主、材料靠近输入。笔记保留切换、编辑、预览和 Markdown 工具，引用去重折叠。
3. **卡片与测验**：单卡复习和集合管理并存；编辑表单按需出现；切任务清除临时编辑状态。测验已选材料时不再重复显示输入框；提供作答进度、解析、只看错题、整体/单道错题制作卡片、练习记录与重新出题保护。
4. **阅读与其余模块**：PDF 缩放设置进入菜单，页码和适应宽度仍常驻；搜索使用自然文案，不改 PDF 渲染逻辑。思维导图生成置于画布上方，编辑与删除保护仍在。网页、视频、图片扩大正文优先级并简化限制提示；三个辅助工具保持独立，不增加材料入口。
5. **验证**：渲染与行为回归、TypeScript、生产构建，以及 Safari 合成数据交互。

### 协作交互的明确变化

- 只有一个兼容工具时直接使用；多个时选择目标；没有时显示“添加…并继续”，取消不会创建模块。
- 快捷发送不创建永久连接，不自动进入专注模式。显式点击来源链接继续沿用来源定位行为。
- 自动收到的原样内容不会反复要求确认。覆盖真正编辑过的输入、已有测验或导图时保留确认。
- 笔记继续追加到当前具体篇目；历史工作台、任务、卡片、测验及运行数据不迁移、不删除。

## 主要改动位置

- `MaterialSelector.tsx`、`LearningInput.tsx`：紧凑材料入口及单一的手动输入呈现。
- `ActionMenu.tsx`、`WorkspaceEditor.tsx`、`workbench.css`：模块容器、低频操作、键盘焦点及宽窄布局。
- `LegacyBody.tsx`、`SourceReferences.tsx`：翻译、对话、笔记的内容层级与折叠来源。
- `LearningModules.tsx`：卡片复习、测验状态/错题、导图生成入口。
- `PdfReader.tsx`、`InputModules.tsx`：阅读与媒体工具的渐进披露和文案。
- `App.tsx`、`learningPresentation.ts`：显式创建目标、接收内容标记及手动草稿保护。
- `services.ts`：读取公开前端环境变量时允许非浏览器测试环境；不改变认证或请求语义。

## 实际测试

- 针对性测试 23/23 通过；最终全量 158/158 通过，TypeScript 检查、生产构建、差异格式检查通过。
- 新测试检查：草稿识别、单来源不重复、材料模式不出现重复输入框、卡片默认单卡、测验答题/解析状态、历史回答引用不随当前材料变化、来源去重及原笔记内容不被改写。
- Safari 使用“数据流全链路验收-独立合成数据”：译文保存笔记、真实 AI 生成卡片、翻面、下一张与翻面重置、集合切换、材料面板取消、来源展开和回跳均已操作。
- Safari 真实 AI 重新生成三道单选题；先验证取消覆盖保留原题，再提交两对一错的作答，正确显示 2/3，练习记录追加为两次；只看错题与单道错题制作卡片已操作，卡片集由六张增加至九张。
- 刷新返回工作台列表后重新打开合成工作台，确认九张卡片、2/3 作答结果、两次练习记录及材料范围均保留。
- Safari 窄翻译模块和专注宽模块已截图检查；宽模块原文、译文并排。标题更多菜单已确认重命名、复制、锁定和移除入口可见，并验证 Escape 关闭。其他媒体主要依靠兼容回归和代码检查，不声称每个控制都经过真实媒体播放验证。

## 剩余限制

- Safari 坐标拖拽接口间歇报 `noWindowsAvailable`；静态文档文本也不提供可设置选区。因此本轮没有完整复测“重新拖选文件段落→悬浮菜单”，只保留并验证了相关组件与既有材料路径，不虚报该端到端结果。
- 不修改历史笔记正文，其中已保存的“AI 生成”等标题或旧参考说明会保留，用户可自行编辑；本次清理的是外围界面。
- 测验仍按现有 AI 协议自动决定数量，未添加实际不生效的题量设置；历史简答题继续保留，明确不自动判分。
- 卡片当前翻面、浏览位置和集合/编辑面板属于会话状态；刷新恢复卡片与任务数据，不恢复未保存的临时表单。
- 未执行跨设备 Supabase 实测、部署、发布或线上迁移。本轮数据操作仅针对已有独立合成验收工作台。
