# 工作台角落辅助工具

- 创建方案和模块库仍提供待办、日历、番茄钟。只有工作台实际包含对应模块时，右下角才显示该工具图标；不默认添加三件套。
- 点击图标展开一个非模态小面板，再次点击或按 Escape 收起。点击画布默认收起，使用图钉可保持展开；展开与固定状态只保留当前界面会话。
- 待办显示未完成数量。运行中的番茄钟收起后继续运行，图标旁显示倒计时，并可直接暂停。
- 同一类型有多个实例时，共用一个图标，面板下拉框按名称和序号切换。原实例 ID、任务内容及运行状态不合并。
- 在搭建模式，面板标题栏可移除当前工具；已有撤销机制可恢复。退出或切换任务不会创建、删除工具。
- 工具正文只在浮层渲染，不在主画布重复渲染；收起只隐藏，不卸载，因此临时输入和计时保持。
- 新增模块和一键布局将辅助工具的旧布局元数据缩成兼容模板的占位，不挤占主画布列宽。已有工作台打开时保留主模块原布局，可主动一键重排回收旧空位。
- 继续使用原有 ModuleBody、任务状态、IndexedDB、云端工作台载荷及模板保存机制，无数据库迁移、无线上写入验证。

验证覆盖：未选择不显示、仅显示已选择类型、多个实例合并图标、主画布排除辅助工具、计时状态计算、布局合法与不重叠、任务隔离、IndexedDB 恢复及模板安装。Safari 视觉和交互操作未实测。
