# 学习任务第一阶段：实现与验收

本阶段新增可编辑 AI 学习计划、多任务进度与成果快照，保留 16 种模块和 V1 模板。不包含 Workflow 自动执行器或社区模板 V2。

## 实现

- `Workspace.tasks` 保存有独立 ID 的任务，`activeTaskId` 指向唯一活动任务。新字段可选，沿用现有 IndexedDB，无需清空或升级数据库。
- AI 预览支持编辑目标、步骤、关联工具、模块组合与成果要求，应用前执行结构和关系校验。创建工作台时随安装事务保存计划。AI 调整现有工作台会创建新任务，保留旧任务进度及成果。
- 任务面板支持创建、切换、暂停、继续、步骤确认、完成、重新打开和收起。共享模块及其内容，任务进度相互独立，不为每个任务复制模块内容。
- 笔记、卡片集和测验可关联到明确步骤，保存当时快照。后续编辑或移除模块不改变旧成果。完成任务需确认全部步骤、至少关联一项成果，并由用户检查成果要求。
- `Mod.activeNoteId` 统一笔记编辑器与跨模块接收目标；不存在时与编辑器使用相同回退规则。原文摘录、AI 生成和用户编辑分别标记，旧笔记显示来源类型未记录，不推断历史内容。
- `safeTemplate` 仍只输出 V1 布局白名单，任务、成果及当前笔记 ID 不进入模板导出或发布。

## 浏览器验收

1. `npm run dev`，在 Safari 打开终端显示的本地地址。
2. 登录并用自然语言创建学习空间。在预览修改目标、步骤、模块和成果要求；移除步骤所需工具时，应提示关联错误并禁止应用，修复后才能创建。
3. 创建后进入学习模式，任务面板显示持久化计划；刷新并重新打开工作台，目标和步骤仍在。
4. 使用原有笔记、卡片或测验模块保存内容，在任务面板明确选择步骤与内容，点击关联。
5. 勾选步骤，点击完成并确认成果要求；回顾中应显示已完成步骤、成果和关联时快照。
6. 创建第二项任务，暂停、继续并切换；第一项任务的完成状态与成果不应变化。收起面板后原模块仍可独立使用。
7. 在笔记模块创建 A、B 两篇，保持 B 激活。从文本模块选段发送到笔记，确认框应指向 B；确认后只有 B 被追加。AI 回答保存时应标为 AI 生成，不应作为原文块引用。
8. 继续编辑原笔记，回顾的旧快照不应变化；移除来源模块后快照仍可查看。模板导出仍不包含任务与正文。

## 本轮验证记录

- 自动化覆盖任务状态、成果快照、IndexedDB 保存恢复、V1 模板隐私、当前笔记落点、AI/原文内容标记、AI 草案字段校验及实例对应。
- Safari 在独立端口 `127.0.0.1:5177` 使用合成内容验证了：新工作台、任务创建、笔记关联、完成回顾、刷新恢复、第二任务暂停/继续、收起面板、文本选段发送到笔记 B，以及 A 篇未被追加。
- 本轮未调用真实模型、未发布社区模板、未操作原站点本地数据。AI 预览与成果要求用受控结果进行结构/渲染测试，真实模型端到端流程仍需登录后验证。

## 已知边界

- 模块正文在任务之间共享，不提供任务专属聊天、卡片或测验会话；成果快照和进度独立保存。
- AI 计划沿用模块类型关联，同类型多个实例初始均可关联；任务面板可进一步按实例调整。
- 步骤和成果要求由用户确认，不自动评价学习效果。成果关联是手动操作，支持笔记、卡片集和当前测验。
- 任务与成果仅保存到当前浏览器；V1 模板导出不是完整备份，也不包含任务计划。
- 任务编辑沿用现有自动保存与失败提示，不支持多标签页协同编辑。

## 第二阶段更新 · 2026-10-16

前文“模块内容共享”为第一阶段边界，已被本节替代。

- 共享布局，任务独立保存模块状态；笔记以 `taskId` 隔离。切换任务会重新挂载模块并清除临时选区，取消旧请求。显式复用操作复制状态和独立笔记 ID，不共享可变正文。
- 旧工作台在首次读取时做可重复的增量升级：自由学习原件保留，已有任务获得原共享状态和笔记的独立副本，原进度与成果快照保留。升级与笔记保存使用现有 IndexedDB 事务。
- 新增“云端任务”：用户逐个工作台开启同步，保存用户确认后的 AI 计划、修改后的目标/步骤、任务内容、笔记和成果快照。账号通过 RLS 隔离，写入使用版本比较 RPC；冲突停止上传并保留本地修改，恢复到已有设备另存独立副本。
- 原始文件只在本地，云端保存文本和来源元数据。换设备后文件需重新选择；历史文件版本引用不能伪装为已恢复。
- 已有 Supabase 项目执行 `005_learning_workspaces.sql`；新项目完整 SQL 已包含同一迁移。本次不部署或发布。
- 同步上限每工作台 5 MB，列表显示最近 50 项；不支持实时协同、自动合并、云端删除或离线后台同步。登录不自动上传未开启的工作台；切换账号不将其他账号绑定的数据上传。
- `scripts/learning-browser-check.ts --synthetic` 提供仅回环地址的隔离浏览器验收：合成身份、本地 PostgreSQL，AI 仍调用真实配置。不能将其当成真实 Supabase 登录与写入验收。
